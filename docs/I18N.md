# Internationalisatie (NL/EN)

## Aanpak

Eén Next.js-applicatie, twee locales, via **next-intl** — geen twee losse
sites en geen dubbele componenten. Nederlands is de standaardtaal.

- NL: geen prefix — `nkgc.nl/diensten/koppelbehandeling`
- EN: `/en`-prefix met een **eigen, natuurlijk Engels pad** —
  `nkgc.nl/en/services/herd-hoof-care`

Dit wordt geconfigureerd via `routing.pathnames` in `src/i18n/routing.ts`:
elke interne route-key (bv. `/diensten/koppelbehandeling`) heeft een NL- én
een EN-pad. next-intl rewrite't dit transparant naar de onderliggende
Next.js-routestructuur (`src/app/[locale]/diensten/koppelbehandeling`).

**Let op (bekende valkuil):** bij `localePrefix: "as-needed"` voegt
next-intl het `/en`-prefix automatisch toe. De `en`-waarden in `pathnames`
mogen dus **niet** zelf met `/en` beginnen — dat gaf tijdens ontwikkeling
een dubbel prefix (`/en/en/services`), inmiddels gefixt. Zie de comment
bovenin `routing.ts`.

## Taalwisselaar blijft op dezelfde pagina

`LanguageSwitcher.tsx` gebruikt `router.replace({ pathname, params }, {
locale })` uit `next-intl/navigation`. Omdat `pathname` de **interne**
route-key is (niet de zichtbare URL), lost next-intl automatisch de juiste
localized URL op. Een bezoeker op `/diensten/koppelbehandeling` die naar EN
wisselt komt dus op `/en/services/herd-hoof-care`, nooit op de Engelse
homepage.

## Content

- Doorlopende teksten en UI-labels: `src/messages/nl.json` /
  `src/messages/en.json`, één-op-één dezelfde sleutelstructuur.
- Structurele/repeterende content (team, workshops, onderzoek, partners):
  `src/content/*.ts`, met een `{ nl: string; en: string }`-paar per
  vertaalbaar veld.

## Engelse vertaling — reviewstatus

De Engelse teksten in `en.json` zijn een eerste, professionele vertaling
(niet machinaal/letterlijk). Conform de opdracht geldt echter uitdrukkelijk:

> Specialistische veterinaire terminologie mag niet blind worden verzonnen.

**Termen die NKGC inhoudelijk zou moeten controleren vóór publicatie:**

| NL-term | Gebruikte EN-vertaling | Waarom controleren |
|---|---|---|
| Koppelbehandeling | "Herd hoof care" / "herd treatment" | Geen gevestigde Engelse vakterm gevonden; NKGC's internationale contacten (bv. Charles Sturt University-netwerk van Jan Lievaart) gebruiken mogelijk een specifieke term |
| Klauwbekapbox / KVK800 | "hoof-trimming crush" | "Crush" is Brits-Engels veeteeltjargon; in Noord-Amerikaanse context is "hoof trimming chute" gebruikelijker — kies bewust op basis van doelgroep |
| Liggedrag / HOBO-meters | "lying behaviour" / "HOBO data loggers" | HOBO is een merknaam (Onset Computer Corp.) — correct als het daadwerkelijk dat apparaat betreft |
| Erfbetreder | "farm advisor" | Nederlands begrip zonder exacte Engelse tegenhanger; vertaling is functioneel, niet letterlijk |
| Tweedelijns advies | "second-line advice" (impliciet, niet als vaste term vertaald) | Medische connotatie van "second-line" kan verwarrend zijn in Engelstalige veterinaire context |

Deze tabel staat bewust ook hier (niet alleen inline in code) zodat een
niet-technische NKGC-reviewer 'm kan doorlopen zonder in de codebase te
hoeven kijken.
